# Student Performance Dashboard (MACSE503, Assessment 7, Q1)

## How to run
1. Install Python 3 from https://www.python.org/downloads/ (tick "Add Python to PATH" during install).
2. Open a terminal / command prompt in this folder and run:

       pip install -r requirements.txt
       streamlit run app.py

3. The dashboard opens in the browser at http://localhost:8501

## Files
- app.py          : Streamlit application
- students.csv    : dataset (student_id, student_name, math_score, science_score, english_score, attendance_percentage)
- requirements.txt: libraries needed
